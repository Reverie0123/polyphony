# Changelog

## 0.1.0 (unreleased)

- Phase 1 skeleton: local server with token / Host / Origin checks, JSON store, accounts and contacts, model discovery, direct and group chat with @mentions and quotes, streaming replies over SSE, usage normalisation (input / output / cache read / cache write / reasoning), cost per message with built-in and online price tables, cost ledger, cancel and regenerate, privacy line, two-column UI with a resizable side panel, Chinese and English UI.
- Providers: OpenAI-compatible (DeepSeek default), Anthropic, Ollama, local `claude` and `codex` CLIs.
- Phase 2: rolling summary by a secretary model, image and text-file attachments (vision contact or Windows OCR, cached by hash), edit & resend, forward, star, pin, Markdown export, global search, @nickname parsing in text.
- Phase 3: free discussion (list / random / host / race order, round gap, no-objection / repetition / budget / end-marker / user stops, summariser, pause / resume / recover), model-to-model mention cards with an auto mode, role-card templates.
- Phase 4: DeskDock member: built-in MCP stdio client, driver model + tool loop with step cards, one-off driver override, confirmation card when a model mentions DeskDock, install / connect / restart from Settings; tool-call messages for OpenAI-compatible, Anthropic and Ollama.
- Phase 5: updater (npm registry check, in-place update for global installs, restart), LAN access QR code (own encoder), icon, Inno Setup installer with portable Node, install.ps1, fixture recorder.
- Multi-role positioning (2026-10-16): the group wizard can generate several role contacts from one base contact and a template (one API key is enough), contacts can be copied as a new role, README leads with roles.
- Fixes after the eighth review (2026-10-16): generated roles with a suffix are reused instead of duplicated on repeated clicks, HTTP error codes are shown translated in the UI, renaming a contact cannot clash with another member of a group it belongs to; error responses can carry named values that the translated message shows (which nickname, which group).
- Fixes after the seventh review (2026-10-16): a truncated .tmp is validated before it can replace a good file (ledger included), member nicknames must be unique within a group and generated roles get a suffix on clashes, DeskDock stays selected after generating roles, the DeskDock tool loop obeys the watchdog settings, mention cards approved during a discussion count toward its budget.
- Fixes after the sixth review (2026-10-16): pending renames are flushed at exit and recovered from .tmp at startup, atomic ledger rewrite, dead discussion branches removed, extra unsummarised messages shown, stream watchdog minutes exposed in Settings.
- Fixes after the fifth review (2026-10-16): idle / total watchdog on every streamed reply, no model hand-offs inside a running discussion, unsummarised messages never drop out of the window (summary threshold lowered), quotes obey whisper visibility, @ matching needs word boundaries, MCP start failure kills the child and unknown reverse requests get an error, official-registry installs with mirror fallback, summary dirty race via epochs, prerelease semver.
